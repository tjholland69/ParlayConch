# Parlay Tracker

A full-stack web application for tracking weekly NFL parlay betting challenges with friends.  
Users can log parlays, view historical performance, and analyze trends through interactive charts.

---

## 🚀 Features

- Create weekly parlays (10–12 legs per entry)
- Track individual bets and linked parlays
- View historical betting data
- Filter dashboards by week, user, and performance
- Add new entries through a data entry form
- Future support for external data imports (e.g., FanDuel, Pro Football Reference)
